# INT8 보정 장수 비교 계획

v1.0.1의 `artifacts/road.keras`와 `artifacts/split.json`을 고정한다. 공개 학습 기록의 SHA-256과 일치하는 KITTI Road ZIP을 사용한다. 가중치 학습은 추가로 수행하지 않는다.

| 보정 장수 | 선택 방법 | 반복 |
|---:|---|---:|
| 3 | UM, UMM, UU 각 1장 | 시드 17, 42, 731 |
| 9 | 같은 시드의 앞 3장에 6장 추가 | 같은 시드 3개 |
| 26 | 원래 변환에 사용한 cal 전체를 원래 순서로 입력 | 1회 |

원본 평가 영상 62장(그중 UU 22장)에 기존 전처리, INT8 단일 스레드 실행기, 임계값 0.5를 적용한다. 기존 평가와 같이 유효한 픽셀의 TP, FP, FN을 먼저 합산하고 도로 IoU를 계산한다. 전체와 UU를 각각 보고한다.

- **재현 기준**은 26장 재변환의 전체 도로 IoU가 공개 결과와 소수 둘째 자리 백분율(77.55%)에서 일치하는 것이다. 이 기준을 충족하지 못하면 보정 장수에 대한 결론은 보류한다.
- **충분성 기준**은 세 시드 각각에서 전체 IoU가 26장 재측정값보다 0.5%p 넘게 낮아지지 않는 것이다. 반올림 전 값으로 판정한다. 0.5%p는 이번 비교에서 정한 허용 오차다. UU는 별도로 보고한다.
- **선택 민감도**는 같은 장수에서 세 시드의 최댓값과 최솟값 차이(%p)로 표시한다.
- **장면 선택**은 여섯 축소 조건과 26장 기준을 같은 장면끼리 대조해, 도로 여부가 달라진 유효 픽셀의 비율이 가장 큰 경우로 한다. 동률이면 적은 보정 장수, 작은 시드, 이미지 ID 사전순으로 고른다.

```bash
python -m src.calibration_experiment --archive work/data/data_road.zip --out work/calibration
```
