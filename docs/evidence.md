## 읽는 순서와 재현

1. [실행 명령과 결과표](../README.md)에서 환경과 다운로드 방법을 확인한다.
2. [학습·모델 구조](training.md), [평가 조건](evaluation.md), [컴파일러의 CPU/NPU 배치](runtime.md)에서 각각의 산출물로 이동한다.
3. [테스트 소스](../tests)와 [현재 제출본 테스트 출력](../artifacts/checks/submission-pytest.txt)을 확인한다. 브라우저 회귀 스크립트는 데스크톱 및 모바일 크기의 Chromium에서 동일한 장면·정답·슬라이더·링크·스크롤 너비를 검사한다.
4. 배포본의 `release.json`은 원본 커밋과 모든 배포 파일의 SHA-256을 담는다. [검증 스크립트](../scripts/verify_release.py)는 원격 파일을 다시 받아 대조한다.
5. 새 입력으로 실행할 때는 [단일 이미지 CLI](../src/infer.py)와 README의 예제를 사용한다. 62개 평가 원본에서 PNG로 저장해 다시 읽은 두 마스크의 혼동행렬을 장면별 측정 CSV와 대조했다. [입출력과 예외 회귀 검사](../tests/test_infer.py)

2026년 11월 27일 제출 점검에서 기준 벤치마크를 새 출력 경로에 다시 실행했다. 원본·합성 저조도·합성 가림 186행의 장면별 측정 CSV가 공개 원본과 바이트 단위로 일치했다. Vela에서 FP32·INT8·혼합 진단 모델을 다시 컴파일해 세 연산 배치 JSON도 확인했다. 공개 시점의 CPU 지연시간은 측정 당시 값을 유지한다.

## 수행 주체

사용자가 직무, 기간, 평가·디자인 기준을 정하고 공개 GitHub 저장소를 개설했다. 지원자는 보정 장수 비교를 설계하고 INT8 재변환·평가·검산을 구현했다. Codex는 기준 모델과 벤치마크, 데모를 제작하고 지원자 실험을 재현·통합·배포했다. 선행 프로젝트 작성자의 기여는 [고정 커밋별 조사](prior.md)에 출처별로 표시했다. 기존 저장소의 소스 파일을 복사한 항목은 없다.

## 공개 버전의 검증 자료

[검증 릴리스](https://github.com/sokldjs554/roadlens-int8/releases/tag/v1.0.0)에 v1.0.0의 커밋, 공개 파일 해시 대조 기록과 화면별 검사 출력을 보존한다. 모바일 검증은 Chromium의 터치·모바일 뷰포트 에뮬레이션이다. 실물 스마트폰이나 iOS Safari의 결과는 포함하지 않는다.

후속 수정에서는 첫 화면의 재생 표시를 저장된 평가 장면 6개와 3초 결과 요약을 담은 21초 영상으로 연결했다. [재생 검사](../tests/replay_smoke.py)는 자바스크립트를 끈 브라우저에서도 진입, 시간 진행, 일시정지, 탐색, 재개, 종료와 복귀를 확인한다. [영상 생성 코드](../scripts/make_replay.py)
