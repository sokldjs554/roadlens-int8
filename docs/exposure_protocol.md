# 입력 밝기 보정 평가 계획

Codex 후속 실험. 공개 실험에서 합성 저조도 실패를 확인한 뒤 정한 탐색적 평가다. 원래 학습·보정·평가 분할과 출시된 26장 보정 INT8 가중치를 고정한다.

- 전처리 규칙은 학습 201장만 사용한다. 192×64 RGB에서 각 장면의 평균 휘도(0.2126R + 0.7152G + 0.0722B)를 구한다. 학습 장면 평균들의 하위 10백분위보다 어두운 입력만 학습 중앙값을 향해 RGB에 동일 배율을 적용한다. 배율 상한은 3, 출력 범위는 [0,1]이다. 완전 검정 입력은 그대로 둔다.
- 원본 62장, 기존 밝기 35%·중앙 가림 각 62장, 고정 감마 2.0으로 어둡게 만든 62장을 비교한다. 네 조건은 동일 장면에 대한 대응 비교다. 감마 조건은 밝기 감소 방식이 달라질 때의 민감도를 보려고 추가한다.
- **기본 경로 적용 후보 기준**은 고정 INT8 모델 대비 조건별 합산 도로 IoU로 판정한다. 원본 하락 ≤0.2%p, 가림 하락 ≤0.5%p, 밝기 35% 개선 ≥5%p, 감마 조건 하락 ≤0.5%p를 모두 요구한다. 또한 원본 한 장에서라도 5%p 넘게 하락하면 후보에서 제외한다. 값은 반올림 전에 비교한다.
- 시각화는 원래 데모의 실패 장면과 원본 조건에서 하락 폭이 가장 큰 장면을 함께 기록한다. 탐색에 사용된 기존 평가 분할이므로 새 주행·실제 야간에 대한 독립 검증은 별도로 필요하다.
