## 범위 결정

마감 전에 독립적으로 검증할 수 있는 전방 카메라 도로 분할을 선택했다. KITTI Road는 직접 촬영한 주행 이미지, 유효 평가 영역, 픽셀 단위 도로 정답과 원본 주행 ID 매핑을 공개한다. 객체 검출은 박스·NMS 변환까지 포함해 비교 변수가 늘고, VLA는 행동 정답과 폐루프 평가 환경이 필요하다. 이번 실험은 고정된 CNN과 입력으로 수치 정밀도만 바꾼다. 픽셀 평가는 이미지 평면에서 한다. KITTI 공식 BEV 순위에는 제출하지 않았다. [데이터와 공식 평가법](https://www.cvlibs.net/datasets/kitti/eval_road.php)

실행 순서는 주행 ID 분할, 학습, FP32 변환, 독립 보정 집합으로 INT8 변환, 동일 CPU에서 비교, Arm Ethos-U55용 Vela 분석, 정적 데모 재생 순이다. 실제 야간·작은 객체에 대한 라벨이 없는 데이터의 한계는 합성 스트레스 조건과 구분한다. 연구용이며 차량 제어·안전성 평가 범위는 포함하지 않는다.

## 기여 기록

사용자는 직무, 과제 목표, 참고 저장소, 마감, 비교·배포·검증 기준을 정하고 빈 공개 GitHub 저장소를 직접 만들었다. 지원자는 [INT8 보정 장수 비교](../artifacts/calibration/README.md)의 설계·구현·측정·검산을 수행했다. Codex는 기준 프로젝트의 공고와 선행 저장소 조사, 데이터 선정과 분할, 코드와 인터페이스 작성, 모델 학습과 변환, 컴파일·CPU 측정, 테스트, 공개 데모 제작·배포를 수행했다. 공개 데이터, 프레임워크와 컴파일러 저자는 각 출처에 기재했다. 선행 프로젝트의 수치와 개인별 기여 근거는 별도 조사표에 있다.
